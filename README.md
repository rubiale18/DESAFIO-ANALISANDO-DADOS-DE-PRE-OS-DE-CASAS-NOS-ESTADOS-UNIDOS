# 🏠 Análise de Preços de Casas - Machine Learning

## 📌 Objetivo

Explorar um dataset de preços de casas nos EUA e construir modelos de Machine Learning para prever valores.

## 🔍 Etapas

### 1. Análise Exploratória

* Identificação de variáveis
* Valores faltantes
* Outliers

### 2. Feature Engineering

* Normalização
* Encoding
* Criação de novas variáveis

### 3. Aprendizagem Supervisionada

* Regressão Linear
* Classificação (alto vs baixo preço)

### 4. Aprendizagem Não Supervisionada

* Clusterização
* PCA (redução de dimensionalidade)
* Outliers (LOF)

### 5. Avaliação

* RMSE
* Accuracy
* Comparação entre modelos
